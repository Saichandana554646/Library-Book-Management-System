# Library Book Management System

A Core Java console-based Library Book Management System.

## Requirements
- JDK 21
- Eclipse / IntelliJ IDEA / VS Code

## Features
- Librarian and Member roles
- Register members
- Add and view books
- Issue and return books
- Maximum two active books per member
- One active loan per physical book
- Borrowing history
- Reports
- Distinct-author count using HashSet
- Persistent text-file storage

## Run
Compile all `.java` files and run:

com.library.Main

The application automatically creates:
- data/members.txt
- data/books.txt
- data/loans.txt
- data/report.txt

## Core Java concepts
OOP, abstraction, inheritance, polymorphism, encapsulation, ArrayList, HashSet, enum, exception handling, file handling, Scanner, loops and conditions.
